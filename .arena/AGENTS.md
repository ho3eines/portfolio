# Agent Skills Reference

This project includes agent skills from the official [anthropics/skills](https://github.com/anthropics/skills) repository. When working on tasks, reference the following skills in `.arena/skills/`:

## Quick Reference

| Skill | When to Use |
|-------|-------------|
| `algorithmic-art` | Generative art, p5.js, flow fields, particle systems |
| `brand-guidelines` | Applying brand colors/typography to artifacts |
| `canvas-design` | Creating posters, art pieces, static visual designs |
| `claude-api` | Building apps with Claude API / Anthropic SDK |
| `doc-coauthoring` | Co-authoring professional documents |
| `docx` | Word documents (.docx) |
| `frontend-design` | Frontend design with React, Tailwind, shadcn/ui |
| `internal-comms` | Internal communications writing |
| `mcp-builder` | Building MCP servers |
| `pdf` | PDF creation and editing |
| `pptx` | PowerPoint presentations (.pptx) |
| `skill-creator` | Creating new skills |
| `slack-gif-creator` | Animated GIFs for Slack |
| `theme-factory` | Applying themes to slide decks |
| `web-artifacts-builder` | Complex HTML artifacts (React + TypeScript + Vite) |
| `webapp-testing` | Testing web apps with Playwright |
| `xlsx` | Excel spreadsheets (.xlsx, .csv, .tsv) |

See `.arena/skills/README.md` for detailed descriptions.
