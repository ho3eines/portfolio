# مهارت‌های عامل (Agent Skills)

این دایرکتوری شامل ۱۷ مهارت از ریپوزیتوری رسمی [anthropics/skills](https://github.com/anthropics/skills) است که به قابلیت‌های عامل اضافه شده‌اند.

## ✨ مهارت‌های خلاقانه و طراحی

| مهارت | توضیح |
|--------|-------------|
| `algorithmic-art` | خلق هنر الگوریتمی با p5.js، فلو فیلدها و سیستم‌های ذره‌ای |
| `canvas-design` | طراحی پوستر، آثار هنری و طرح‌های استاتیک در فرمت PNG/PDF |
| `frontend-design` | طراحی فرانت‌اند با ری‌اکت، Tailwind و اجزای shadcn/ui |
| `theme-factory` | اعمال تم‌های رنگی و تایپوگرافی حرفه‌ای به اسلایدها و آثار |
| `web-artifacts-builder` | ساخت آرتیفکت‌های پیچیده HTML با React، TypeScript، Vite و Tailwind |
| `slack-gif-creator` | ساخت گیف‌های متحرک برای اسلک |

## 💻 مهارت‌های توسعه و فنی

| مهارت | توضیح |
|--------|-------------|
| `claude-api` | مرجع کامل Claude API و Anthropic SDK برای ساخت اپلیکیشن‌های LLM |
| `mcp-builder` | ساخت سرورهای MCP با پروتکل Model Context Protocol |
| `webapp-testing` | تست اپلیکیشن‌های تحت وب با Playwright |

## 🏢 مهارت‌های سازمانی و ارتباطی

| مهارت | توضیح |
|--------|-------------|
| `brand-guidelines` | اعمال رنگ‌ها و تایپوگرافی برند Anthropic |
| `doc-coauthoring` | هم‌نویسی اسناد حرفه‌ای |
| `internal-comms` | نوشتن ارتباطات داخلی سازمانی |

## 📄 مهارت‌های اسناد

| مهارت | توضیح |
|--------|-------------|
| `docx` | ایجاد و ویرایش فایل‌های Word (.docx) |
| `pdf` | ایجاد و ویرایش فایل‌های PDF |
| `pptx` | ایجاد و ویرایش ارائه‌های PowerPoint (.pptx) |
| `xlsx` | ایجاد، ویرایش و تحلیل فایل‌های Excel (.xlsx, .csv, .tsv) |

| مهارت | توضیح |

| `skill-creator` | راهنما برای ساخت مهارت‌های جدید |
